# PCCX SystemVerilog IDE v2026.5.24

Initial public source release for the PCCX SystemVerilog IDE scaffold.

## Included

- Scanner-backed Python CLI for fixture-based diagnostics, module indexing,
  declaration lookup, module organization views, xsim log parsing, and editor
  problem export shapes.
- Local VS Code prototype scaffold with checked-example defaults and opt-in
  live workspace commands.
- Apache-2.0 license, contribution guide, security policy, quickstart, and
  smoke test entry point.

## Validation

```bash
bash scripts/smoke.sh
python -m pytest -q
git diff --check
```

## Boundary

This source release is local and fixture-backed. It does not publish a
Marketplace extension, run vendor tools, touch hardware, call providers,
upload source, or publish binary artifacts.
